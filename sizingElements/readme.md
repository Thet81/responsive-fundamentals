# Percentages: Height & Width

- We can use percentages to size non-text HTML elements relative to their parent elements.

- They are often used to size box-model values such as `width`, `heigth`, `padding`, `border` and `margins` and can also be used for positioning properties (top, bottom, left, right)

- When `width` and `height` are set using percentages, the dimensions of child elements are calculated based on the dimensions of the parent element.

- When percentages are used to set padding and margin, they are calculated based only on the `width` of the parent element.
